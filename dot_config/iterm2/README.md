## iTerm2 macOS Terminal Emulator preferences file

The file [`com.googlecode.iterm2.plist`](./com.googlecode.iterm2.plist) is loaded by iTerm2 when the **Load preferencesfrom a custom folder or URL** setting is enabled in **iTerm2 → General → Preferences**.
